# Easy Settings — Jiya + Jimmy ❤️

Open `index.html` and look at the very top, immediately after `<head>`.

Edit only:

```js
const LOVE_CONFIG = {
  herName: "Jiya",
  yourName: "Jimmy",
  meetingDate: "2026-11-20T20:30:00",
  secretWord: "love",
  pageTitle: "For Jiya, From Jimmy ♡"
};
```

## Meeting time
Use:
`YYYY-MM-DDTHH:MM:SS`

Examples:
- 20 Nov 2026 at 8:30 PM → `2026-11-20T20:30:00`
- 1 Dec 2026 at 7:00 PM → `2026-12-01T19:00:00`

## Secret password
Change:
`secretWord: "love"`

to:
`secretWord: "your-private-word"`

After saving, commit the changed `index.html` to GitHub Pages.
